# AI for Retail — Hands-On Labs

**Course Code:** C398  |  **1 day, 7.5 instructional hours**  |  **9 labs**  |  **Version v1.0**

All labs run on one connected scenario: **Bloom & Brew**, a fictional specialty home, gift and coffee retailer with six outlets and an online store. The synthetic data in [`resources/`](resources/) carries through the whole day, so each lab builds on the one before it. No programming is required — every lab is done in a browser with an AI assistant and a spreadsheet.

## Data files

Everything in [`resources/`](resources/) is **synthetic** — generated by [`tools/make_sample_data.py`](../tools/make_sample_data.py) with a fixed seed, so every learner gets identical files and the verification steps always hold. There is no real customer, payment or employee data anywhere in this repository.

| File | What it is | Used by |
|---|---|---|
| `products.csv` | 24 SKUs with material, size, origin, care, certification, cost, retail and stock | Labs 2, 3, 5, 6, 7, 8 |
| `customers.csv` | 60 customers **with** names, emails and phone numbers | Lab 4 |
| `transactions.csv` | 591 order lines over the last 6 months | Labs 4, 6, 8, 9 |
| `sales_history_monthly.csv` | 24 months of unit sales by SKU and category | Lab 7 |
| `customer_feedback.csv` | 30 enquiries, reviews and complaints | Labs 5, 9 |
| `store_policies.md` | Returns, delivery, loyalty, care and privacy policy | Lab 5 |
| `faq.md` | 20 customer FAQs, consistent with the policy | Lab 5 |
| `brand_voice.md` | Tone of voice rules the copy is judged against | Labs 2, 3 |

`transactions.csv` and `sales_history_monthly.csv` reconcile exactly over the last six months, so a number checked in one file can be verified against the other.

## How to use a lab

Each lab README carries the same structure: **Goal**, **What you'll build**, **Prerequisites**, numbered **Steps** with the exact prompt to paste, **Test it**, **Troubleshooting**, a **Challenge** for fast finishers and a **Reflection** question. Work through them in order. If you fall behind, every lab states the file it starts from, so you can rejoin at any lab.

> **Note:** Use only the synthetic data supplied and accounts you are authorised to use. Never paste real customer, payment or employee data into a public AI tool.
